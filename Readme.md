# Annual Computer Science Symposium 2026

A responsive, single-page website for the **Annual Computer Science Symposium**, built using plain HTML5 and CSS3. The website presents event information, displays the event schedule, highlights a featured speaker, and provides a student registration form with HTML5 validation.

## Features

- **Event Landing Page:** Introduction and overview of the symposium.
- **Event Schedule:** Structured HTML table displaying events, timings, and venues.
- **Navigation Menu:** Fixed navigation bar with links to different sections.
- **Featured Speaker:** Speaker card with an absolute-positioned Keynote badge.
- **Student Registration:** Form with name, university email, semester, age, and attendance motivation fields.
- **Form Validation:** Required fields, email pattern validation, and minimum/maximum age restrictions.
- **Modern UI:** Gradient header, styled sections, event cards, hover effects, and a clean color scheme.
- **Responsive Design:** CSS media queries for smaller screens.

## Technologies Used

- CSS3

No frameworks or external CSS libraries are used.

## Assignment Requirements

The project demonstrates the following concepts:

1. **Semantic HTML:** Proper document structure, metadata, headings, sections, image, and footer.
2. **Tables and Lists:** Event schedule table, ordered list, and unordered navigation list.
3. **HTML5 Forms:** Different input types and client-side validation.
4. **CSS Styling:** Element, class, and ID selectors, pseudo-classes, box model, and responsive layouts.
5. **Positioning:** Fixed navigation, relative and absolute positioning, and `z-index`.

## Important Note

The registration form currently demonstrates front-end validation. A backend is required to process and permanently store submitted registrations.

The event image is loaded from an external URL, so an internet connection is required to display it.
