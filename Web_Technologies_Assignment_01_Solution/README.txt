HOW TO USE
1. Extract this ZIP file.
2. Open any Task folder and double-click index.html, or open it in VS Code.
3. For Task 8, Task 9 and Task 10, keep each task's style.css in the same folder as index.html.
4. Internet is required for the remote library images and embedded video in Task 2. Replace these with locally saved, copyright-permitted media if your instructor requires local files.
5. Add your own name and registration number to the assignment cover page / submission form before submitting.
6. Submit this complete source folder as a ZIP, as required by the assignment. If your LMS asks for a document too, include screenshots of each task in a separate PDF.
