# Web Technologies

This repository contains **all my contributions to the Web Technologies course** at COMSATS University Islamabad, Sahiwal Campus. It includes my lab tasks, assignments, and practical work completed throughout the course.

## 📚 About

The purpose of this repository is to maintain and showcase my learning and progress in web development, from basic HTML elements to CSS styling, forms, tables, and complete webpage layouts.

## 🛠️ Technologies Used

- **HTML5** — Webpage structure and content
- **CSS3** — Styling, layouts, and responsive design
- **Forms and Tables** — Organizing information and collecting user input
- **Links and Media** — Navigation, images, and embedded videos

## 📂 Repository Contents

This repository may include:

- Lab tasks and practical exercises
- Course assignments
- HTML and CSS webpages
- Forms, tables, and page layouts
- Web design templates
- Personal portfolio and other practice projects

Each folder contains the relevant source files for its task or project.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the folder for the task you want to explore.
3. Open the `index.html` file in your web browser.
4. If a task uses an external CSS file, keep it in the same folder as its HTML file.

## 🎯 Learning Goals

Through this coursework, I aim to strengthen my understanding of HTML, CSS, webpage structure, styling, and the fundamentals of front-end web development.
